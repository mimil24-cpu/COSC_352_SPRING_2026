# Project 6 - Baltimore City Homicide Dashboard

## Overview
Interactive Shiny dashboard for Baltimore City Police Department to analyze homicide trends.

## Features
- **Visualizations**: Monthly trends, age distribution, method analysis, district breakdown
- **Filters**: Year, age range, method, sex
- **Summary Stats**: Total homicides, average age, most common method
- **Data Table**: Searchable/sortable records

## Data Source
Scrapes live data from Baltimore Sun homicide tracker (2023-2025)

## Technologies
- R: shiny, shinydashboard, rvest, dplyr, stringr, lubridate, plotly, DT
- Docker for containerization
